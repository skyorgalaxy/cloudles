## 3.6 推荐学习顺序

```text
局域网体系结构
  -> Ethernet V2 帧格式
  -> CSMA/CD 原理与计算
  -> 802.11 与 CSMA/CA
  -> 802.11 三地址
  -> VLAN 与 802.1Q
  -> 统考真题
```

## 做题优先级

1. 最短帧长、传播时延和最大距离。
2. 二进制指数退避。
3. RTS/CTS、IFS 和 NAV。
4. 802.11 地址 1、2、3。
5. VLAN 广播域和 802.1Q 帧长。
