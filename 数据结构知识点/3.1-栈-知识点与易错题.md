## 一句话抓住栈

栈是只允许在一端进行插入和删除的线性表。允许操作的一端叫栈顶，另一端叫栈底。

- 入栈：Push，插入到栈顶
- 出栈：Pop，删除栈顶元素
- 读栈顶：GetTop，只读取，不删除
- 核心规律：LIFO，后进先出

栈是操作受限的线性表，不是非线性结构。栈和队列的逻辑结构相同，都是线性表；差别在于操作限制不同。

## 顺序栈：先看 top 的定义

题目中最容易错的不是代码本身，而是没有先判断 `top` 表示什么。

### 写法A：top 指向栈顶元素

常见设定：数组下标为 `0...MaxSize-1`，空栈时 `top=-1`，栈向高地址方向增长。

```c
bool StackEmpty(SqStack S) {
    return S.top == -1;
}

bool StackFull(SqStack S) {
    return S.top == MaxSize - 1;
}

bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) return false;
    S.data[++S.top] = x;
    return true;
}

bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) return false;
    x = S.data[S.top--];
    return true;
}

bool GetTop(SqStack S, ElemType &x) {
    if (S.top == -1) return false;
    x = S.data[S.top];
    return true;
}
```

记忆：`top` 指元素，入栈先加后存，出栈先取后减。

### 写法B：top 指向下一个空位置

常见设定：空栈时 `top=0`，数组下标为 `0...MaxSize-1`，栈向高地址方向增长。

```c
Push:    S.data[S.top++] = x;
Pop:     x = S.data[--S.top];
GetTop:  x = S.data[S.top - 1];
Empty:   S.top == 0;
Full:    S.top == MaxSize;
```

记忆：`top` 指下一个空位，入栈先存后加，出栈先减后取。

### 写法C：栈向低地址方向增长

如果空栈时 `top=MaxSize`，`top` 仍表示下一个空位置，但栈向低地址增长：

```c
Push:    S.data[--S.top] = x;
Pop:     x = S.data[S.top++];
GetTop:  x = S.data[S.top];
Empty:   S.top == MaxSize;
Full:    S.top == 0;
```

不要死记 `++top` 或 `--top`。先画出地址增长方向，再决定指针先动还是后动。

## GetTop 和 Pop 的区别

| 操作 | 是否返回栈顶元素 | 是否改变栈 |
| --- | --- | --- |
| `GetTop` | 是 | 否 |
| `Pop` | 是 | 是，删除栈顶 |

题目说“读取”“查看”“取栈顶但不出栈”，选 `GetTop`；题目说“弹出”“删除”“出栈”，才选 `Pop`。

## 共享栈

两个栈共享同一个数组空间：

```text
栈1 -> [低地址 ---------------- 高地址] <- 栈2
       top1                         top2
```

常见设定：数组 `Share[0...n-1]`，栈1从左向右增长，栈2从右向左增长。

```text
top1 = -1
top2 = n
```

共享栈满的条件：

```text
top2 - top1 == 1
```

易错点：共享栈不是两个独立数组，因此不能用“某一个栈到达数组末端”判断整个共享栈满。只要两个栈顶相邻，整体就满。

## 链栈

链栈通常用不带头结点的单链表表示，栈顶指针 `top` 指向首结点。

```c
bool Push(LinkStack &S, ElemType x) {
    LinkNode *p = (LinkNode *)malloc(sizeof(LinkNode));
    p->data = x;
    p->next = S.top;
    S.top = p;
    return true;
}

bool Pop(LinkStack &S, ElemType &x) {
    if (S.top == NULL) return false;
    LinkNode *p = S.top;
    x = p->data;
    S.top = p->next;
    free(p);
    return true;
}
```

链栈的入栈和出栈都在表头进行，时间复杂度为 `O(1)`。若把栈顶放在链表尾部，出栈通常需要找到前驱，单链表中会变成 `O(n)`，这是设计上的低效选择。

## 出入栈序列题

### 四步模拟法

1. 从第一个入栈元素开始扫描。
2. 当前想输出的元素不在栈顶，就继续入栈。
3. 当前想输出的元素已经在栈顶，就出栈。
4. 如果它在栈中但不在栈顶，序列非法；如果所有元素都处理完，序列合法。

示例：入栈序列 `1,2,3,4`，判断输出 `2,1,4,3`：

```text
入1，入2，出2，出1，入3，入4，出4，出3
```

所以合法。

### 三个高频结论

- 只有一个元素时，任意入栈和出栈顺序都必须保持这个元素本身。
- 入栈序列为 `1,2,...,n` 时，完全逆序 `n,...,2,1` 一定可以实现。
- 某个元素出栈时，所有比它更早入栈但尚未出栈的元素必须压在它下面，因此不能越过它们直接出栈。

### 判断 I/O 序列是否合法

把 `I` 看作入栈，`O` 看作出栈。扫描序列时：

- 任意前缀中，`O` 的数量不能超过 `I` 的数量，否则试图从空栈出栈。
- 扫描结束后，`I` 和 `O` 的总数必须相等。

只检查总数相等是不够的，`IOOI` 虽然总数相等，但第二个 `O` 时栈已经为空，因此非法。

### Catalan 数：只问数量时使用

`n` 个不同元素按固定顺序入栈，所有可能的出栈序列数量为：

```text
C_n = 1/(n+1) * C(2n,n)
```

前几项：`1, 2, 5, 14, 42, 132`。

注意：这个公式只适用于“固定入栈顺序、一个栈、问所有合法出栈序列数量”的标准模型。题目若限制栈容量、允许多个栈或改变入栈规则，不能直接套用。

## 栈题型和易错点

### 题型1：判断栈的性质

判断关键词：一端操作、后进先出、栈顶、操作受限线性表。

易错点：

- 栈是线性结构，不是非线性结构。
- 栈和队列的逻辑结构相同，都是线性表。
- “存储结构”不是栈的本质定义，顺序栈和链栈都可以表示栈。

### 题型2：顺序栈代码判断

先列出四件事：空栈值、满栈值、增长方向、`top` 指向元素还是空位。只要其中一项未确认，就不要判断 `++` 和 `--`。

### 题型3：共享栈判断

看到 `top1=-1, top2=n`，优先想到 `top2-top1==1`。不要误写成 `top1==top2`，因为两个栈顶可能在同一位置语义上相邻，而不是重合。

### 题型4：出栈序列判断

最稳的方法是模拟。不要只看第一个或最后一个元素，也不要把“元素已经入栈”误认为“元素可以立即出栈”。

### 题型5：栈的应用

- 括号匹配：左括号入栈，右括号必须匹配栈顶左括号。
- 表达式求值：操作数入栈，运算符弹出操作数计算后再入栈。
- 递归和函数调用：保存返回地址、参数、局部变量等调用信息。
- 深度优先搜索、回溯：沿路径深入，失败后撤销到最近决策点。

## 一页速记

```text
栈：一端进出，LIFO
GetTop：看，不删
顺序栈：先确认 top 语义，再决定 ++ / --
共享栈：top1=-1，top2=n，满：top2-top1==1
链栈：头插头删，O(1)
合法出栈：不能越过栈顶；I/O 任意前缀都满足 I>=O，结束时 I=O
数量题：固定入栈顺序的标准模型用 Catalan 数
```
