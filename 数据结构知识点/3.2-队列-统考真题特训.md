## 训练目标

这组真题不只是考“队列是 FIFO”，而是反复考三个能力：

1. 看懂 `front`、`rear` 的具体指向。
2. 通过端点限制判断一个序列能不能产生。
3. 从题目要求反推应该选择顺序、链式、循环或双端结构。

做题顺序建议：

```text
先判断结构模型 -> 写清指针语义 -> 画状态 -> 再开始推序列或公式
```

## 2010 真题：输出受限双端队列

### 题目模型

队列两端都可以入队，但只有一端可以出队。`a,b,c,d,e` 依次入队，问哪个出队序列不可能。

答案：`C`。

### 先把题目翻译成结构

这是输出受限双端队列：

```text
左端：可以入队，也可以出队
右端：可以入队，不能出队
```

因此，元素如果从右端进入，就不能直接从右端出来；它必须等待左侧元素全部处理完，才能成为左端可输出的元素。

### 最短判断：先看前两个元素

入队顺序是 `a,b,c,d,e`。前两个元素 `a,b` 入队后，只可能有两种相对位置：

```text
左端入 a，再入 b：b a
左端入 a，右端入 b：a b
```

无论怎样，`a` 和 `b` 都是相邻的。后续元素只能从两端加入，不能插入 `a` 和 `b` 中间。

选项 `C` 的序列是 `d,b,c,a,e`，其中 `a` 和 `b` 不相邻，因此不可能。

### 为什么其他选项可以

不需要完整模拟所有细节，能找到一种端点操作即可：

```text
A: b,a,c,d,e
B: d,b,a,c,e
D: e,c,b,a,d
```

### 真题方法

这类题优先使用“不变量”，而不是把所有入队、出队步骤全部枚举：

> 端点插入不能打破已经形成的相邻关系。

### 易错点

- “两端都能入队”不等于“任意位置都能插入”。
- “只有一端出队”意味着另一端入队的元素不能直接从原端点删除。
- 看到“不可能”，先找结构不变量；看到“可能”，只要构造一种操作即可。

### 变式训练

若入队顺序为 `1,2,3,4`，仍是两端入队、单端出队，那么判断一个输出序列时，先检查：

- 前两个输入元素是否仍保持相邻。
- 输出端是否真的能轮到目标元素。

## 2011 真题：循环队列初始指针

### 题目模型

循环队列存储在 `A[0...n-1]` 中，非空时 `front` 和 `rear` 分别指向队首元素和队尾元素。初始为空，要求第一个进入的元素存储在 `A[0]`，问初始 `front`、`rear`。

答案：`B`，即：

```text
front = 0, rear = n - 1
```

### 解题关键

题目说的是：

- `front` 指向队首元素
- `rear` 指向队尾元素
- 第一个元素入队后放在 `A[0]`

由于入队通常先执行：

```text
rear = (rear + 1) % n
```

要让第一次入队后 `rear=0`，初始必须是 `n-1`：

```text
(n - 1 + 1) % n = 0
```

第一个元素入队后，队首和队尾都是 `A[0]`，所以 `front=0` 不变。

### 这道题专门防什么

它防止你死记“循环队列初始时 front=rear=0”。这个初值不是永远固定的，必须看：

1. `front` 指元素还是元素前一个位置。
2. `rear` 指元素还是元素后一个位置。
3. 入队是先移动指针还是后移动指针。

### 易错点

- 题目说“非空时”指针的含义，不代表空队列时也必须用相同位置。
- `front=rear=0` 是常见约定，不是循环队列的唯一初值。
- 先写第一次入队的代码，再倒推初始值，比背结论稳。

### 变式训练

若改成：`front` 指向队首元素的前一个位置，`rear` 指向队尾元素，且第一个元素仍放在 `A[0]`，那么初始值的推导过程会改变。遇到这种题，重新画“第一次入队前”和“第一次入队后”两张图。

## 2014 真题：双端循环队列的空和满

### 题目模型

循环数组 `A[0...M-1]`，最多容纳 `M-1` 个元素：

- `end1` 指向队首元素
- `end2` 指向队尾元素的下一个位置
- 两端都能入队和出队

答案：`A`。

```text
队空：end1 == end2
队满：end1 == (end2 + 1) % M
```

### 为什么队空是 `end1 == end2`

`end2` 指向队尾后面的空位置。空队列没有队首元素，也没有队尾元素，因此两个指针回到同一个位置。

### 为什么队满要牺牲一个空位

如果所有 `M` 个位置都使用，两个指针又会相遇，无法区分“空”还是“满”。所以最多只存 `M-1` 个元素，留出一个空位作为标志。

当队列满时，`end2` 的下一个位置正好是 `end1`：

```text
(end2 + 1) % M == end1
```

等价写法就是选项 A 的：

```text
end1 == (end2 + 1) % M
```

### 这道题的固定模板

只要看到下面三个条件：

```text
循环数组
队尾指针指向队尾后一个位置
最多存 M-1 个元素
```

就优先写：

```text
空：front == rear
满：front == (rear + 1) % M
```

但如果题目改成 `rear` 指向队尾元素，公式就不能照搬。

## 2018 真题：队列和栈组合输出

### 题目模型

初始队列为：

```text
1,2,3,4,5,6
```

栈为空，只允许三种操作：

1. 出队并直接输出。
2. 出队并入栈。
3. 出栈并输出。

问哪个输出序列不可能。

答案：`C`，即：

```text
3,4,5,6,1,2
```

### 看到第一个输出 3 时发生什么

要先输出 `3`，队首的 `1,2` 不能直接输出，只能依次出队入栈：

```text
队列：1,2,3,4,5,6
操作：1 入栈，2 入栈
栈顶：2
队列：3,4,5,6
```

现在输出 `3,4,5,6` 没问题。剩下栈中的元素是：

```text
栈顶 -> 2,1
```

因此后续只能输出：

```text
2,1
```

而不能输出 `1,2`。

### 核心规律

队列负责保持原顺序，栈负责把被暂存的部分反转：

```text
被跳过的队首部分：1,2
进入栈后输出：2,1
```

### 其他选项的判断思路

- 若目标从 `1` 开始，可以直接从队列输出。
- 若目标从 `2` 或 `3` 开始，可以把前面的元素送入栈，再决定何时输出。
- 真正危险的是：为了输出后面的元素而把前面元素压栈，但目标又要求这些元素按原顺序返回。

### 易错点

- 栈不是“暂存后还能保持原顺序”的缓冲区。
- 只要两个元素按 `1,2` 顺序入栈，它们从栈出来一定是 `2,1`。
- 不要只判断首元素，必须继续追踪暂存到栈里的元素。

## 2021 真题：一端输入受限的双端队列

### 题目模型

初始为空：

- 一端只能入队。
- 另一端既能入队，也能出队。
- 入队序列为 `1,2,3,4,5`。

问不能得到的出队序列。

答案：`D`，即：

```text
4,1,3,2,5
```

### 先固定左右端语义

设左端为 `L`，右端为 `R`：

```text
L：可入队，可出队
R：只能入队，不能出队
```

这是输入受限双端队列。最关键的限制是：

> 从右端进入的元素，不能直接从右端离开；要等左侧元素全部处理后，才可能轮到它。

### 为什么 4 很难先出来

目标要求第一个输出 `4`。如果 `4` 从右端进入，那么在它右边没有问题，但它不能从右端出队；要从左端出来，必须先处理挡在它左边的 `1,2,3`，这和“4 第一个输出”矛盾。

所以 `4` 必须从左端进入，才能作为当前可输出端的元素。

但如果 `4` 从左端进入，后续 `1,2,3` 的进入位置会决定它们在 `4` 后面的相对顺序。想要在输出 `4` 后得到 `1`，又要之后得到 `3,2`，会与输入顺序和端点插入规则冲突，因此 `4,1,3,2,5` 不可能。

### 做这类题的实用方法

对每个候选序列，不必一上来写完整算法，只问：

1. 第一个要输出的元素能从哪个端进入？
2. 如果从不能输出的一端进入，它前面是否还有挡板？
3. 输出第一个元素后，第二个目标是否能成为可输出端元素？

### 易错点

- “输入受限”限制的是入队端，不是出队端。
- “输出受限”限制的是出队端，不是入队端。
- 不要把 2021 题和 2010 题混为同一种双端队列：两题限制方向相反。

## 2019 综合题：由要求反推队列结构

### 题目要求

设计一个队列，满足：

- 初始为空。
- 入队时允许增加队列占用空间。
- 出队后，原空间可以再次利用。
- 入队和出队始终为 `O(1)`。

### 第一步：排除顺序存储

顺序数组的空间通常在初始化时确定，不能自然满足“入队时不断增加占用空间”。普通顺序队列还会遇到假溢出，搬移元素又可能变成 `O(n)`。

所以应选择链式存储。

### 第二步：为什么不是普通链式队列

普通链式队列出队后如果直接释放结点，就没有“出队空间可重复使用”。题目要求回收利用，因此需要让出队结点留在结构中，循环到队尾重新使用。

可选结构：带 `front`、`rear` 指针的循环单链表，保留一个空结点作为队列的分界。

### 第三步：核心状态

用一个空结点区分队首和队尾：

```text
空队列：front == rear
非空：front 指向队首，rear 指向队尾或约定的空位
```

入队时：

1. 如果循环链表中有可复用的空结点，就把数据写入该结点。
2. 没有可用空间时，动态申请新结点并接入循环链表。
3. 更新 `rear`。

出队时：

1. 取出 `front` 位置的数据。
2. 移动 `front` 到下一个结点。
3. 原结点保留在循环链表中，作为以后入队时可复用的空间。

### 为什么复杂度是 `O(1)`

有队首和队尾指针后：

- 入队只需修改队尾附近的指针。
- 出队只需修改队首指针。
- 不需要遍历查找队尾，也不需要移动大量元素。

因此入队和出队都能保持 `O(1)`。

### 综合题答题骨架

```text
1. 结构选择：链式存储，具体为带 front/rear 的循环单链表。
2. 初始状态：建立一个空结点，front 和 rear 按题设指向同一位置。
3. 队空判断：front == rear。
4. 入队：利用 rear 后面的空结点；若没有则申请并接入；更新 rear。
5. 出队：读取 front 数据；front 后移；原结点不释放，留作循环复用。
6. 复杂度：入队 O(1)，出队 O(1)。
```

## 真题训练卡

### 卡片A：循环队列

看到“循环数组”先写：

```text
next(i) = (i+1) % MaxSize
```

再问：

- `front` 指元素还是前一位置？
- `rear` 指元素还是后一位置？
- 是牺牲空位，还是有 `size/tag`？

### 卡片B：双端队列

看到“某端只能入队/只能出队”，先在纸上写：

```text
左端：入？出？
右端：入？出？
```

然后追踪目标序列的第一个元素和第二个元素。

### 卡片C：栈和队列组合

看到“队列元素进入栈再输出”，马上想到：

```text
队列：保持顺序
栈：反转被暂存的片段
```

重点检查：目标序列是否要求暂存片段恢复为原顺序。

### 卡片D：综合题选结构

把文字要求翻译成结构约束：

| 题目要求 | 结构判断 |
| --- | --- |
| 空间固定、操作下标明确 | 顺序队列/循环队列 |
| 入队时空间可增加 | 链式队列 |
| 出队空间可重复利用 | 循环链式结构或空闲结点管理 |
| 始终 `O(1)` 入队出队 | 必须有合适的队首、队尾指针 |

## 推荐训练流程

### 第1轮：只做模型识别

不计算、不看答案，只写每道题属于：

```text
循环队列 / 双端队列 / 链式队列 / 队列+栈
```

### 第2轮：限时做题

- 20、21、22、23、24：每题 3 分钟
- 2019 综合题：15 分钟

每题必须写出一个理由，不能只写选项。

### 第3轮：只复盘错误类型

把错题归入以下四类之一：

- 指针语义看错
- 空满条件混淆
- 双端限制方向看错
- 暂存到栈后忘记顺序反转

如果同一类错了两次，回到本笔记对应的“训练卡”重新做一遍。
