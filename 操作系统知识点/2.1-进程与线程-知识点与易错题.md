# 2.1 进程与线程 - 知识点与易错题

> 原书：第37-65页；PDF第48-76页

## 1. 进程概念

程序是静态指令集合，进程是程序的一次执行过程，是资源分配和独立运行的基本单位。

特征：动态性、并发性、独立性、异步性、结构性。动态性是进程最基本特征。

## 2. 进程组成

```text
进程实体 = 程序段 + 数据段 + PCB
```

PCB 是进程存在的唯一标志，典型内容：

- 标识信息：PID、用户标识。
- 处理器状态：PC、通用寄存器、PSW、栈指针。
- 调度信息：状态、优先级、队列指针、时间片。
- 资源信息：地址空间、打开文件、I/O 状态。

## 3. 进程内存映像

典型从低地址到高地址：代码段、数据段、堆、共享库/映射区、栈。堆通常向高地址增长，栈通常向低地址增长，具体布局依系统而定。

## 4. 状态与转换

基本三态：运行、就绪、阻塞。加入创建和终止构成五态模型。

```text
就绪 -> 运行：被调度
运行 -> 就绪：时间片到/被抢占
运行 -> 阻塞：主动等待事件或资源
阻塞 -> 就绪：等待事件完成
```

阻塞态不能直接转运行态；就绪态也不能主动转阻塞态。若引入挂起：

- 活动就绪/静止就绪
- 活动阻塞/静止阻塞

挂起通常把进程映像换到外存，阻塞则表示正在等待事件，二者原因不同。

## 5. 进程控制

创建、撤销、阻塞、唤醒和切换通常由内核原语完成。原语在执行期间不可被中断，以保证状态修改原子性。

创建：申请 PCB -> 分配资源 -> 初始化 PCB -> 插入就绪队列。

终止：根据 PID 找 PCB -> 终止其执行 -> 处理子进程 -> 归还资源 -> 删除 PCB。

阻塞由进程自身主动发起；唤醒由其他进程或内核在事件完成后执行，二者成对。

## 6. 进程通信

### 共享存储

多个进程映射同一内存区，速度快，但同步互斥需进程自行协调。

### 消息传递

- 直接通信：明确指定发送/接收进程。
- 间接通信：通过信箱/端口。

消息传递适合分布式系统，内核负责传递，数据复制可能带来开销。

### 管道

管道是内核中的固定大小字节流缓冲区：

- 通常半双工，要双向通信需两个管道；
- 写满则写进程阻塞，读空则读进程阻塞；
- 普通匿名管道多用于有亲缘关系进程；命名管道可用于无亲缘进程。

## 7. 线程

线程是处理器调度的基本单位。同一进程内线程共享：地址空间、代码、全局数据、打开文件等；每个线程独有：线程 ID、PC、寄存器、栈和状态。

引入线程的目的：降低创建/切换成本，提高并发与多核利用率，便于同一应用内部通信。

### 用户级线程 ULT

- 线程管理由用户线程库完成，内核不感知；
- 切换不陷入内核，速度快；
- 一个线程阻塞可能导致整个进程阻塞；
- 多对一模型不能真正并行使用多个 CPU。

### 内核级线程 KLT

- 内核直接管理和调度；
- 一个线程阻塞不妨碍同进程其他线程；
- 可在多核并行；
- 创建和切换开销较大。

### 多线程模型

- 多对一：多个用户线程映射一个内核线程。
- 一对一：每个用户线程对应一个内核线程。
- 多对多：多个用户线程复用多个内核线程。

## 8. 上下文切换

进程切换要保存当前上下文到 PCB，并恢复另一进程上下文，还可能切换地址空间、页表和刷新部分 TLB/Cache 状态。线程切换若在同进程内通常无需切换地址空间，开销较小。

模式切换不等于进程切换：系统调用可只从用户态进入内核态，服务完成后仍返回原进程。

## 易错点

- [ ] 把程序和进程混为一谈
- [ ] PCB 不是进程全部内容，但它是进程存在的唯一标志
- [ ] 运行态因 I/O 完成转就绪（I/O 完成的是阻塞进程）
- [ ] 阻塞态直接被调度为运行态
- [ ] 挂起等同于阻塞
- [ ] 线程共享栈和寄存器
- [ ] 用户级线程一定能在多核并行
- [ ] 内核态切换必然是进程切换

## 一页背诵版

```text
进程：资源分配基本单位
线程：CPU调度基本单位
PCB：进程存在唯一标志

运行->阻塞：主动等待
阻塞->就绪：事件完成
运行->就绪：抢占/时间片到

线程共享：地址空间、代码、数据、文件
线程私有：ID、PC、寄存器、栈、状态
```
