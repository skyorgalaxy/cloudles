# 2.2 CPU 调度 - 知识点与易错题

> 原书：第66-98页；PDF第77-109页

## 1. 调度层次

- 高级调度（作业调度）：从外存后备队列选择作业进入内存，频率最低。
- 中级调度（内存调度）：决定挂起进程何时重新调入内存。
- 低级调度（进程调度）：从就绪队列选进程占用 CPU，频率最高。

## 2. 调度时机

需要调度：进程终止、阻塞、时间片到、出现更高优先级进程等。

不能调度/切换的典型时刻：处理中断关键过程、执行不可中断原语、持有必须立即释放的内核自旋锁等。具体以题设内核设计为准。

- 非抢占式：运行进程主动阻塞或终止才让出 CPU。
- 抢占式：时钟中断或高优先级到达可剥夺 CPU，响应好但开销和同步要求更高。

## 3. 调度指标

```text
周转时间 = 完成时刻 - 到达时刻
带权周转时间 = 周转时间 / 实际运行时间
等待时间 = 在就绪队列等待的总时间
响应时间 = 首次获得CPU时刻 - 到达时刻
```

系统还关注 CPU 利用率、吞吐量、公平性和截止时间。

## 4. 经典算法

### FCFS 先来先服务

按到达顺序，非抢占。公平简单，利于长作业和 CPU 繁忙型，不利于短作业与交互任务，可能出现护航效应。

### SJF/SPF 短作业优先

从已到达任务中选预计运行时间最短者，通常非抢占；平均等待时间理论最优，但需预知运行时间，长作业可能饥饿。

### SRTF 最短剩余时间优先

SJF 的抢占版本，新任务到达且剩余时间更短时抢占。平均等待时间优，但切换多、长任务可能饥饿。

### HRRN 高响应比优先

非抢占：

```text
响应比 = (等待时间+服务时间)/服务时间 = 1+等待时间/服务时间
```

兼顾等待时间与短作业，等待越久优先级越高，可缓解饥饿。

### 优先级调度

可抢占或非抢占。静态优先级固定；动态优先级随等待或运行变化。低优先级可能饥饿，可用老化逐步提高等待进程优先级。

通常系统进程、交互型/I/O 型进程可获得较高优先级，具体规则以题设为准。

### RR 时间片轮转

就绪队列按 FCFS，运行一个时间片未完成则回队尾。

- 时间片过大：退化为 FCFS。
- 时间片过小：响应快，但切换开销过大。
- 适合分时与交互系统。

### 多级反馈队列 MLFQ

- 多个优先级队列，高优先级时间片较小；
- 新进程先入最高级队列；
- 用完时间片未完成则降级；
- 高优先级队列优先运行，可配老化防止饥饿。

兼顾短作业、交互任务和长作业，无需预知运行时间。

## 5. 进程切换

调度是决定运行谁，切换是保存/恢复上下文并真正交接 CPU。一次调度决定不一定引起切换，例如仍选择当前进程。

切换是系统开销，不完成用户有效工作；时间片选择需平衡响应与切换成本。

## 6. 多处理器调度

- 非对称多处理：主处理器负责调度与系统工作，实现简单，主处理器可能瓶颈。
- 对称多处理 SMP：各处理器自调度，可用公共就绪队列或每核队列。
- 处理器亲和性：尽量让进程继续在原 CPU 上运行，以复用 Cache。
- 负载均衡：迁移任务，避免部分 CPU 空闲。

## 7. 甘特图解题模板

```text
1. 按到达时间列出进程
2. 每个决策点只考虑已经到达者
3. 明确是否抢占、优先级数值方向、时间片
4. 画运行区间，记录首次运行和完成时刻
5. 计算周转、带权周转、等待、响应
```

若 CPU 空闲到下一个进程到达，甘特图必须画出空闲区间。

## 易错点

- [ ] 把作业调度、内存调度、进程调度混淆
- [ ] 周转时间漏减到达时刻
- [ ] 响应时间算成完成时间
- [ ] SJF 在未到达进程中提前选择
- [ ] 不区分 SJF 与 SRTF 是否抢占
- [ ] RR 新到达进程与时间片结束进程的入队顺序未按题设
- [ ] 认为优先级调度天然不会饥饿
- [ ] 把调度等同于上下文切换

## 算法速查

| 算法 | 抢占性 | 优势 | 主要问题 |
| --- | --- | --- | --- |
| FCFS | 否 | 简单公平 | 护航效应 |
| SJF | 否 | 平均等待时间优 | 需预测、长作业饥饿 |
| SRTF | 是 | 短任务响应好 | 抢占多、长任务饥饿 |
| HRRN | 否 | 兼顾长短 | 每次需算响应比 |
| 优先级 | 均可 | 体现重要性 | 低优先级饥饿 |
| RR | 是 | 交互响应好 | 时间片选择困难 |
| MLFQ | 是 | 综合适应性好 | 参数复杂 |
