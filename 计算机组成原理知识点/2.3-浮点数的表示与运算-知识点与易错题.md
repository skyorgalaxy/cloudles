# 2.3 浮点数的表示与运算 - 知识点与易错题

> 原书：第53-75页；PDF第64-86页
>
> 本节核心：IEEE 754、浮点加减、舍入与溢出、C 数值转换、大小端、边界对齐

## 先建立整体框架

浮点数用“科学计数法”思想在有限位数内兼顾范围与精度：

```text
N = (-1)^S × M × R^E
```

- `S`：符号。
- `M`：尾数，决定有效精度。
- `E`：阶码，决定数值范围。
- `R`：基数，二进制浮点数通常为 2。

IEEE 754 把机器数分为：

```text
符号位S | 阶码字段E | 尾数字段F
```

规格化数的解释公式为：

```text
(-1)^S × 1.F × 2^(E-Bias)
```

> [!tip] 解码时固定四步
> 拆 S/E/F -> 判断特殊类别 -> 求真实阶码 -> 还原有效数并计算真值。

## 1. IEEE 754 标准浮点数

### 1.1 单精度与双精度格式

| 格式 | 总位数 | 符号 | 阶码 | 尾数 | 偏置 Bias | 规格化有效位 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 单精度 `float` | 32 | 1 | 8 | 23 | 127 | 24 |
| 双精度 `double` | 64 | 1 | 11 | 52 | 1023 | 53 |

规格化数的小数点前固定为 1，因此最高有效位 `1` 不存入尾数字段，称为隐藏位。

```text
单精度：(-1)^S × 1.F × 2^(E-127)，1<=E<=254
双精度：(-1)^S × 1.F × 2^(E-1023)，1<=E<=2046
```

### 1.2 为什么采用偏置阶码

阶码需要表示正负指数。将真实阶码加一个偏置后，阶码字段可按无符号数存储和比较。

```text
阶码字段E = 真实阶码e + Bias
真实阶码e = E - Bias
```

IEEE 754 的偏置为 `2^(k-1)-1`，而教材一般移码常以 `2^(k-1)` 为偏置，两者相差 1，不能直接混用。

### 1.3 规格化数的范围

#### 单精度

```text
最小正规格化数：1.0 × 2^-126
最大正规格化数：(2-2^-23) × 2^127
```

#### 双精度

```text
最小正规格化数：1.0 × 2^-1022
最大正规格化数：(2-2^-52) × 2^1023
```

“范围”主要由阶码位数决定，“精度”主要由尾数有效位数决定。

### 1.4 阶码全 0 或全 1 的特殊值

| 阶码E | 尾数F | 数值类别 | 真值 |
| --- | --- | --- | --- |
| 全0 | 全0 | 正零/负零 | `+0` 或 `-0` |
| 全0 | 非0 | 非规格化数 | `(-1)^S × 0.F × 2^(1-Bias)` |
| 全1 | 全0 | 正无穷/负无穷 | `+∞` 或 `-∞` |
| 全1 | 非0 | NaN | 非数 |
| 非全0、非全1 | 任意 | 规格化数 | `(-1)^S × 1.F × 2^(E-Bias)` |

#### 非规格化数

非规格化数没有隐藏位 1，使用固定阶 `1-Bias`，用于表示 0 与最小规格化数之间的数，实现渐进下溢。

```text
单精度最小正非规格化数：2^-149
双精度最小正非规格化数：2^-1074
```

#### 无穷与 NaN

- 非零有限数除以 0、结果超过最大有限值等可能得到无穷。
- `0/0`、`∞-∞`、负数开平方等非法实数运算可得到 NaN。
- NaN 与任何值（包括它自己）的相等比较通常为假。

> [!warning] 阶码全 0 不能直接套规格化公式
> 规格化数补隐藏位 `1`；非规格化数补 `0`，并使用真实阶码 `1-Bias`。

## 2. IEEE 754 编码与解码

### 2.1 十进制真值转 IEEE 754

```text
1. 判断符号位S
2. 将绝对值转为二进制
3. 规格化为 1.F × 2^e
4. 计算阶码字段 E=e+Bias
5. 去掉隐藏位1，截取/舍入尾数F
6. 拼成 S | E | F，并按需要转十六进制
```

例：将 `-8.25` 转为单精度：

```text
-8.25 = -1000.01₂ = -1.00001₂ × 2^3
S=1
E=3+127=130=10000010₂
F=00001000000000000000000

机器数：1 10000010 00001000000000000000000
十六进制：C1040000H
```

### 2.2 IEEE 754 机器数求真值

```text
1. 十六进制展开为完整二进制
2. 按 1/8/23 或 1/11/52 分字段
3. 先检查E是否全0或全1
4. 规格化数：e=E-Bias，M=1.F
5. 真值=(-1)^S×M×2^e
```

例：单精度 `C6400000H`：

```text
1 | 10001100 | 10000000000000000000000
S=1
E=140，e=140-127=13
M=1.1₂=1.5
真值=-1.5×2^13
```

### 2.3 快速估算与校验

- 正规格化数：符号位 0，阶码越大通常数值越大。
- 负规格化数：绝对值越大，真值越小。
- 数值为 `2^k` 时尾数全 0，阶码为 `k+Bias`。
- 编码后应检查字段位数：单精度必须严格为 `1+8+23=32` 位。

## 3. 浮点数加减运算

浮点加减通常分五步：

```text
对阶 -> 尾数加减 -> 规格化 -> 舍入 -> 溢出判断
```

### 3.1 对阶

目标是使两操作数阶码相等。基本原则：

```text
小阶向大阶看齐
阶码每加1，尾数右移1位
```

不能让大阶向小阶对齐，因为大阶尾数左移可能移出最高有效位，造成不可逆的严重错误。

对阶右移时：

- 符号位不参与移位；
- 规格化数的隐藏位 1 要随尾数右移；
- 移出的低位不要立即丢弃，应保留为附加位参与后续运算和舍入。

若两阶差远大于有效位数，小数的有效位会全部移出，按舍入规则后结果可能等于大数。

### 3.2 尾数加减

阶码相等后，尾数按定点小数进行加减。隐藏位应还原并参与运算，附加位也参与但不直接存入最终格式。

### 3.3 规格化

运算后尾数要调整为 `1.xxx...`。

#### 右规

若尾数相加产生形如 `10.xxx`：

```text
尾数右移1位，阶码加1
```

右规通常至多一次。

#### 左规

若结果形如 `0.00...1xxx`：

```text
尾数左移，阶码相应减小
直到最高有效位恢复为1
```

相近数相减可能出现大量前导 0，因此左规可能多次。

### 3.4 舍入

对阶与规格化会移出低位。为提高精度，常保留三类附加信息：

| 名称 | 含义 |
| --- | --- |
| 保护位 G | 最低保留位之后的第一位 |
| 舍入位 R | 保护位之后的一位 |
| 粘滞位 S | 更低所有移出位的逻辑或 |

IEEE 754 常见舍入方式：

1. **就近舍入，遇中间值取偶数**：默认方式。选择距离最近的可表示数；恰在中点时让最终尾数最低有效位为 0。
2. **向正无穷舍入**：选择不小于真值的最小可表示数。
3. **向负无穷舍入**：选择不大于真值的最大可表示数。
4. **向零截断**：直接丢弃多余位，也称朝原点舍入。

就近舍入常用判断：

```text
G=0：直接舍去
G=1 且 (R=1 或 S=1)：尾数加1
G=1 且 R=0 且 S=0：恰为中点，按最低有效位奇偶决定
```

舍入使尾数加 1 后可能再次产生进位，需要再右规并调整阶码。

### 3.5 溢出判断

真正决定浮点溢出的是**最终阶码**，不能只看尾数是否进位。

- 阶码大于最大规格化阶：上溢，结果趋向无穷或最大有限数，取决于舍入模式。
- 阶码低于最小规格化阶：先进入非规格化范围；若继续过小则下溢为机器零。

> [!warning] 尾数溢出不等于浮点数溢出
> 尾数产生进位通常可通过右规解决；只有右规后阶码超出上限，才是真正上溢。

### 3.6 浮点运算不满足的数学性质

由于有限精度和舍入：

- 浮点加法通常满足交换律，但不保证结合律。
- 浮点乘法通常也不保证结合律。
- 大数加很小的数时，小数可能在对阶中被完全舍去。

例：若 `x` 很大、`y` 与 `z` 很小，则 `(x+y)+z` 与 `x+(y+z)` 可能不同。

## 4. C 语言中的浮点类型与转换

### 4.1 常见类型

- `float` 通常对应 IEEE 754 单精度。
- `double` 通常对应 IEEE 754 双精度。
- `long double` 的长度和格式依编译器与平台而定。

常见类型提升方向：

```text
char -> int -> long -> double
float -> double
```

混合运算通常先把较低类型转换为较高类型，再运算。

### 4.2 int 转 float

32 位 `int` 的有效整数位最多可达 32 位，而单精度只有 24 位有效数字：

- 通常不会范围溢出；
- 绝对值较大的整数可能因舍入而失去低位精度；
- 绝对值不超过 `2^24` 的整数可被单精度精确表示；超过后并非每个整数都可表示。

### 4.3 int 转 double

双精度有 53 位有效数字，因此 32 位整数可被精确表示，通常既不溢出也不丢失精度。

### 4.4 float 转 double

单精度数的范围和精度均包含在双精度中，因此通常可精确转换。

### 4.5 double 转 float

可能发生两类问题：

- 数值超出单精度范围，产生上溢或下溢；
- 尾数有效位由 53 位降至 24 位，发生舍入和精度损失。

### 4.6 浮点转整数

- 小数部分通常直接截断，方向朝 0。
- 若真值超出目标整数范围，则会发生整数溢出，具体语言行为需结合标准和平台；统考题按题设处理。

### 4.7 判断转换等式的技巧

逐步检查：

```text
1. 目标类型的范围是否足够
2. 目标类型的有效位是否足够
3. 是否经历过不可逆的舍入或截断
4. 后续再转回高精度，丢失的信息也不会自动恢复
```

例如 `int -> float -> double` 中，若在转 `float` 时已经损失低位，再转 `double` 只能精确保存那个近似值，无法恢复原整数。

## 5. 数据的宽度与存储

### 5.1 bit、Byte 与 word

| 单位 | 含义 |
| --- | --- |
| bit（b） | 一个二进制位，最小信息单位 |
| Byte（B） | 8 bit，基本存储与编址单位 |
| word | 体系结构定义的数据处理单位 |
| 字长 | CPU 定点整数运算数据通路的宽度，常与通用寄存器宽度一致 |

字长不一定等于“字”的字节数。例如某些体系结构中“字”仍固定指 16 位，而处理器字长已是 32 位。

### 5.2 大端与小端

现代计算机通常按字节编址。多字节数据 `0x01234567` 从地址 `0x0800` 开始：

| 地址 | 大端 | 小端 |
| --- | --- | --- |
| `0800H` | `01H` | `67H` |
| `0801H` | `23H` | `45H` |
| `0802H` | `45H` | `23H` |
| `0803H` | `67H` | `01H` |

记忆：

```text
大端：MSB在低地址，书写顺序与地址递增顺序一致
小端：LSB在低地址，连续字节需逆序组合还原数值
```

> [!warning] 大小端只改变字节顺序
> 单个字节内部各位的正常书写次序不因此颠倒；寄存器中的逻辑数值也不因内存端序改变。

### 5.3 从机器代码读取立即数

小端机器中，多字节立即数在内存里按低字节到高字节排列。读取时先按地址顺序取出，再将连续字节逆序组合成通常书写的十六进制数。

### 5.4 边界对齐

边界对齐要求数据起始地址是其对齐值的整数倍。常见规则：

```text
char：按1字节对齐
short：按2字节对齐
int/float：按4字节对齐
double：常按8字节对齐（以题设平台为准）
```

对齐可减少跨存储单元访问次数，提高存取效率，但会引入填充字节。

### 5.5 结构体对齐

常见规则：

1. 每个成员的起始地址必须是该成员对齐值的整数倍。
2. 成员之间必要时插入填充。
3. 结构体整体大小是其最大成员对齐值的整数倍，末尾必要时补齐。

例（32 位常见规则）：

```c
struct A {
    int a;    // 偏移0~3
    char b;   // 偏移4
    short c;  // 偏移6~7，偏移5填充
};            // 总大小8
```

```c
struct B {
    char b;   // 偏移0
              // 偏移1~3填充
    int a;    // 偏移4~7
    short c;  // 偏移8~9
              // 偏移10~11尾部填充
};            // 总大小12
```

成员顺序改变会影响填充量与结构体总大小。

### 5.6 地址计算模板

```text
1. 写出结构体首地址
2. 按成员顺序计算当前偏移
3. 将偏移上调到该成员对齐值的整数倍
4. 分配该成员所需字节
5. 全部成员结束后，将总长度上调到最大对齐值的整数倍
6. 若问某字节内容，再结合大小端排列
```

## 高频易错点

- [ ] 把 IEEE 阶码字段直接当真实阶码
- [ ] 单精度尾数只有 23 位，就认为有效精度也是 23 位
- [ ] 对非规格化数补隐藏位 1
- [ ] 把阶码全 1、尾数非 0 解释为无穷
- [ ] 忘记 `+0` 与 `-0` 有不同位串
- [ ] 对阶时让大阶向小阶对齐
- [ ] 对阶移位后立即丢弃低位，不参与舍入
- [ ] 左规时阶码加 1，或右规时阶码减 1
- [ ] 看到尾数进位就直接判上溢
- [ ] 就近舍入的中点情况忘记“取偶数”
- [ ] 认为浮点加法满足结合律
- [ ] 认为任意 32 位 int 都能精确转为 float
- [ ] 认为 float 转 double 能恢复此前损失的精度
- [ ] 把大小端理解成每个字节内部比特顺序也颠倒
- [ ] 只计算结构体成员间填充，漏掉尾部填充

## 一页背诵版

```text
IEEE 754规格化数：(-1)^S × 1.F × 2^(E-Bias)

float：1+8+23，Bias=127，有效位24
double：1+11+52，Bias=1023，有效位53

E全0,F全0：±0
E全0,F非0：非规格化，0.F×2^(1-Bias)
E全1,F全0：±∞
E全1,F非0：NaN

单精度：
最小正规格化数 2^-126
最小正非规格化数 2^-149
最大有限数 (2-2^-23)×2^127

浮点加减：对阶 -> 尾数加减 -> 规格化 -> 舍入 -> 溢出
对阶：小阶向大阶，尾数右移
右规：尾数右移，阶码+1
左规：尾数左移，阶码-1
最终是否溢出看阶码

大端：MSB低地址
小端：LSB低地址
结构体：成员分别对齐，总大小按最大对齐值补齐
```

## 自测

1. 写出 IEEE 754 单精度和双精度的字段宽度、偏置值和有效位数。
2. 阶码全 0、尾数非 0 时为什么不能补隐藏位 1？
3. 将 `-8.25` 编为 IEEE 754 单精度十六进制。
4. 解码单精度 `C6400000H`。
5. 默写浮点加减五步骤，并说明对阶方向。
6. 右规与左规时阶码分别如何改变？
7. 为什么尾数进位不一定发生浮点上溢？
8. 32 位 int 转 float 是否一定精确？转 double 呢？
9. `0x12345678` 在小端机器从低地址到高地址如何排列？
10. 按常见 4 字节对齐规则，计算 `struct {char a; int b; short c;}` 的成员偏移与总大小。

### 自测答案

1. 单精度 `1/8/23`、Bias 127、24 位有效；双精度 `1/11/52`、Bias 1023、53 位有效。
2. 这是非规格化数，定义的有效数为 `0.F`，用于填补 0 与最小规格化数之间的区间。
3. `C1040000H`。
4. `-1.5×2^13=-12288`。
5. 对阶、尾数加减、规格化、舍入、溢出判断；小阶向大阶对齐。
6. 右规阶码加 1；左规每移一位阶码减 1。
7. 尾数可通过右规恢复格式；只有调整后的阶码超出上限才上溢。
8. int 转 float 不一定精确；32 位 int 转 double 通常精确。
9. `78H、56H、34H、12H`。
10. `a` 偏移0，填充1~3，`b` 偏移4~7，`c` 偏移8~9，尾部填充10~11，总大小12字节。
