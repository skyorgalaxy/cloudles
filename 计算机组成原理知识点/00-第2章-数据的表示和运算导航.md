## 全章核心关系图

```text
真值
├─ 整数
│  ├─ 无符号数：直接按位权解释
│  └─ 有符号数：通常采用补码
│      ├─ 加减：统一交给加法器
│      ├─ 乘法：部分积 + 移位
│      └─ 除法：试商 + 加减 + 移位
└─ 实数
   ├─ 定点表示：小数点位置固定
   └─ 浮点表示：符号 + 阶码 + 尾数
       └─ IEEE 754：偏置阶码 + 隐藏位 + 特殊值
```

## 全章必背公式

```text
n位无符号整数范围：0 ~ 2^n-1
n位补码整数范围：-2^(n-1) ~ 2^(n-1)-1

[x-y]补 = [x]补 + [-y]补  (mod 2^n)
补码加减溢出：OF = Cn XOR Cn-1
无符号加法进位：CF = Cout
无符号减法借位：CF = NOT Cout（按本书加减器口径）

IEEE 754 规格化数：(-1)^S × 1.F × 2^(E-Bias)
单精度：1 + 8 + 23，Bias=127，有效位24位
双精度：1 + 11 + 52，Bias=1023，有效位53位
```

## 学习顺序

```text
先会进制转换
  -> 再掌握补码范围与求法
  -> 再做补码加减、溢出和移位
  -> 再理解乘除硬件过程
  -> 最后学习 IEEE 754 编码、运算和 C 类型转换
```

## 全章最常见失分点

- [ ] 把数值位数和机器字长混为一谈
- [ ] 求负数补码时忘记符号位也参与按位取反加一
- [ ] 忘记补码最小负数没有对应的正数
- [ ] 用有符号溢出规则判断无符号进位，或反过来
- [ ] 把逻辑右移和算术右移混用
- [ ] 认为乘积、被除数扩展到双字长后仍可忽略高半部分
- [ ] IEEE 754 阶码直接当真值使用，忘记减偏置值
- [ ] 对非规格化数错误地补隐藏位 1
- [ ] 浮点加减时让大阶向小阶对齐
- [ ] 认为浮点加法满足数学上的结合律
- [ ] 混淆大端/小端与位的左右书写顺序
- [ ] 忽略结构体成员间和末尾的对齐填充

## 章节验收

学完后应能独立完成：

1. 任意十进制整数、小数与二进制之间的转换。
2. 给定字长，求原码、反码、补码、移码及表示范围。
3. 判断 C 语言有符号/无符号转换后的机器数与真值。
4. 根据 `ZF、SF、OF、CF` 判断加减结果。
5. 手算补码加减和定点移位，并正确判断溢出。
6. 解释乘除法器中寄存器、ALU、移位器和控制逻辑的作用。
7. 在十进制、二进制与 IEEE 754 十六进制机器数之间转换。
8. 完整写出浮点加减五步骤。
9. 分析 `int、float、double` 相互转换是否精确或溢出。
10. 根据内存字节序和对齐规则求变量各字节地址。
