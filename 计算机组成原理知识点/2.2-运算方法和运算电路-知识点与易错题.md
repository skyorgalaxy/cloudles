# 2.2 运算方法和运算电路 - 知识点与易错题

> 原书：第32-53页；PDF第43-64页
>
> 本节核心：全加器、ALU、补码加减、标志位、移位、乘法器和除法器

## 先建立硬件主线

```text
一位全加器
  -> n位加法器
  -> 加减法器
  -> ALU
  -> 配合寄存器、移位器和控制逻辑
  -> 实现加、减、乘、除及逻辑运算
```

运算器通常包括 ALU、移位器、状态寄存器 PSW 和通用寄存器组。ALU 的核心部件是加法器。

---

## 1. 基本运算部件

### 1.1 一位全加器

一位全加器 FA 有三个输入：`A_i、B_i、C_{i-1}`；两个输出：本位和 `S_i` 与向高位进位 `C_i`。

```text
S_i = A_i XOR B_i XOR C_(i-1)
C_i = A_iB_i + (A_i XOR B_i)C_(i-1)
```

也可定义：

```text
生成信号 G_i = A_iB_i
传递信号 P_i = A_i XOR B_i
C_i = G_i + P_iC_(i-1)
```

### 1.2 串行进位加法器

n 个全加器级联，低位进位依次传向高位。

- 优点：结构简单。
- 缺点：高位结果必须等待低位进位逐级传播；字长越长，延迟越大。

这里的“串行进位”不是每次只计算一位，而是各位加法器同时接收操作数，**进位信号串行传播**。

### 1.3 并行进位加法器

又称先行进位加法器。它根据各位生成/传递信号并行求出进位，缩短进位链延迟，速度高于串行进位，但电路更复杂。

### 1.4 带标志加法器

n 位加法器除结果 `F` 外，通常还产生：

| 标志 | 含义 |
| --- | --- |
| ZF | 结果是否为 0 |
| SF | 结果最高位，即有符号结果的符号 |
| OF | 有符号运算是否溢出 |
| CF | 无符号运算是否产生进位/借位 |

### 1.5 算术逻辑单元 ALU

ALU 在控制信号作用下，可对输入执行加、减、与、或、异或、移位等操作。ALU 的位数通常与机器字长相关。

> [!warning] ALU 不保存长期结果
> ALU 是组合逻辑运算部件，操作数和结果通常由寄存器暂存；运算类型由控制信号选择。

## 2. 定点数的移位运算

### 2.1 三种移位

| 类型 | 左移补位 | 右移补位 | 主要用途 |
| --- | --- | --- | --- |
| 逻辑移位 | 低位补0 | 高位补0 | 无符号数、位操作 |
| 算术移位 | 依编码规则 | 保持符号意义 | 有符号数乘除2 |
| 循环移位 | 移出位回填另一端 | 移出位回填另一端 | 位循环、带进位循环 |

### 2.2 逻辑移位

无符号数在不丢失有效位的前提下：

```text
逻辑左移 k 位：乘 2^k
逻辑右移 k 位：整除 2^k
```

左移丢失高位 1 可能发生溢出；右移丢失低位会损失精度。

### 2.3 补码算术移位

- 左移：低位补 0，符号位通常保持；若移位后高有效位与符号矛盾，则可能溢出。
- 右移：高位补原符号位，低位丢弃。

补码算术右移对负数的效果通常相当于向负无穷方向取整，而不是简单向 0 截断。

例：8 位补码 `10010101` 算术右移一位：

```text
11001010
```

### 2.4 原码和反码的算术移位

- 原码：符号位不动，数值位左右移动，空位补 0。
- 反码：符号位不动；正数空位补 0，负数空位补 1。

> [!warning] 算术右移不是一律补 1
> 补码负数才在高位补 1；补码正数和无符号逻辑右移均补 0。

## 3. 定点数加减运算

### 3.1 补码加减

补码把加法与减法统一为加法：

```text
[A+B]补 = [A]补 + [B]补       (mod 2^n)
[A-B]补 = [A]补 + [-B]补      (mod 2^n)
```

运算规则：

1. 操作数必须具有相同位数。
2. 符号位与数值位一起参与运算。
3. 最高位产生的进位直接丢弃，结果保留 n 位。
4. 丢弃进位只完成模运算；是否溢出要另行判断。

### 3.2 加减法器如何统一

设控制信号 `Sub`：

```text
Sub=0：Y原样进入，最低位进位 Cin=0，执行 X+Y
Sub=1：Y逐位取反，最低位进位 Cin=1，执行 X+NOT(Y)+1=X-Y
```

因此只需一套 n 位加法器，加上异或门/多路选择器，即可实现加法和减法。

### 3.3 有符号溢出的本质

n 位补码能表示的范围有限。只有以下情况可能溢出：

```text
同号数相加，结果异号
异号数相减，结果符号异常
```

正数加正数得到负数是正溢出；负数加负数得到正数是负溢出。异号相加不会溢出。

### 3.4 三种溢出判断法

#### 方法一：一位符号位

加法时，设两操作数符号为 `A_s、B_s`，结果符号为 `S_s`：

```text
OF = A_sB_s NOT(S_s) + NOT(A_s)NOT(B_s)S_s
```

即输入同号、结果异号时溢出。

#### 方法二：最高位进位异或

```text
OF = C_n XOR C_(n-1)
```

`C_n` 是符号位产生的进位，`C_(n-1)` 是进入符号位的进位。

#### 方法三：双符号位

使用两位符号 `S_s1S_s2`：

| 双符号位 | 结论 |
| --- | --- |
| `00` | 正数，无溢出 |
| `01` | 正溢出 |
| `10` | 负溢出 |
| `11` | 负数，无溢出 |

```text
OF = S_s1 XOR S_s2
```

### 3.5 四个标志位

#### 零标志 ZF

```text
结果所有位均为0 -> ZF=1
否则 -> ZF=0
```

ZF 对有符号数和无符号数都有意义。

#### 符号标志 SF

```text
SF = 结果F的最高位
```

仅在按有符号数解释时有意义；若发生溢出，SF 不等于真实数学结果的符号。

#### 溢出标志 OF

判断补码有符号运算是否超出范围：

```text
OF = C_n XOR C_(n-1)
```

OF 对无符号运算没有意义。

#### 进/借位标志 CF

本书的统一加减器定义为：

```text
CF = Sub XOR C_out
```

- 加法 `Sub=0`：`CF=C_out`，有最高进位时 CF=1。
- 减法 `Sub=1`：`CF=NOT(C_out)`，发生借位时 CF=1。

CF 用于无符号运算，对有符号溢出判断没有意义。

> [!warning] OF 与 CF 完全不是一回事
> 同一位串运算可出现 `OF=1、CF=0`，也可出现 `OF=0、CF=1`；关键看结果按有符号还是无符号解释。

### 3.6 用标志位比较大小

执行 `A-B` 后：

#### 无符号比较

```text
ZF=1          -> A=B
ZF=0 且 CF=0 -> A>B
CF=1          -> A<B
```

#### 有符号比较

```text
ZF=1                 -> A=B
ZF=0 且 (SF XOR OF)=0 -> A>B
ZF=0 且 (SF XOR OF)=1 -> A<B
```

发生溢出时，SF 需要由 OF 修正。

### 3.7 原码加减法

原码运算要分符号与绝对值：

- 加法：同号绝对值相加，结果符号不变；异号则大绝对值减小绝对值，结果取大数符号。
- 减法：先改变减数符号，再按原码加法处理。

因控制复杂，现代计算机通常用补码进行整数加减。

## 4. 定点乘法运算

### 4.1 乘法的共同思想

二进制乘法可化为：

```text
根据乘数当前位决定是否加被乘数
  -> 部分积移位
  -> 重复n次
```

n 位数与 n 位数的完整乘积最多需要 2n 位保存。若只保留低 n 位，必须检查高 n 位是否为合法扩展，才能判断是否溢出。

### 4.2 原码乘法

- 符号：两个操作数符号异或。
- 数值：两个绝对值按无符号乘法计算。

典型无符号迭代乘法器包括：

| 部件 | 作用 |
| --- | --- |
| 被乘数寄存器 X | 保存被乘数 |
| 乘数寄存器 Y | 每轮检查最低位 |
| 乘积寄存器 P | 累积高半部分积 |
| 进位触发器 C | 保存加法进位 |
| ALU | 完成部分积加法 |
| 移位器 | 对 `[C,P,Y]` 整体右移 |
| 计数器 | 控制 n 轮迭代 |

每轮：

```text
若Y最低位为1：P <- P+X
若Y最低位为0：P不变
[C,P,Y]整体逻辑右移一位
```

n 轮后完整乘积在 `[P:Y]` 中。

### 4.3 补码乘法与 Booth 思想

补码乘法的符号位和数值位一起参与运算。Booth 算法考查相邻两位：

| 当前位与辅助位 | 操作 |
| --- | --- |
| `00` 或 `11` | 不加减 |
| `01` | 加被乘数 |
| `10` | 减被乘数 |

随后将部分积、乘数和辅助位整体算术右移。考试通常重点考硬件结构、循环步骤和溢出判断，而非复杂推导。

### 4.4 乘法实现方式

| 实现 | 特点 |
| --- | --- |
| 迭代乘法器 | 复用 ALU 与移位器，成本低，约需 n 轮 |
| 阵列乘法器 | 并行产生并压缩部分积，速度快、硬件多 |
| 编译器移位相加 | 常数乘法可拆为移位与加减，硬件成本最低但指令较多 |

### 4.5 乘法溢出

- 无符号：低 n 位作为结果时，高 n 位全 0 才不溢出。
- 有符号补码：高 n 位必须是低 n 位符号位的符号扩展，才不溢出。

## 5. 定点除法运算

### 5.1 运算前判断

以无符号整数为例：

- 被除数为 0、除数非 0：商 0、余数 0。
- 被除数小于除数：商 0、余数为被除数。
- 除数为 0：产生除零异常。
- 只有被除数和除数均非 0 且被除数不小于除数时，进入正式迭代。

### 5.2 无符号恢复余数除法

常用寄存器：除数 `Y`、余数/被除数高部 `R`、商/被除数低部 `Q`。

每轮：

```text
1. [R,Q]整体逻辑左移一位
2. 试减：R <- R-Y
3. 若R>=0：本位商1，保留差值
4. 若R<0：本位商0，R <- R+Y 恢复
```

n 轮后，商在 Q，余数在 R。

### 5.3 加减交替法

又称不恢复余数法。若本轮余数为负，下轮不先恢复，而改做加除数；若为正则继续减除数，从而减少一次恢复操作。

### 5.4 补码除法

补码除法同时处理符号和数值。被除数通常要先符号扩展到双字长，商和余数需满足：

```text
被除数 = 除数 × 商 + 余数
|余数| < |除数|
余数符号通常与被除数相同
```

两个 n 位补码数相除时，典型商溢出只有一种特殊情形：

```text
最小负数 ÷ (-1)
```

结果为 `2^(n-1)`，超出 n 位补码正数上限。

### 5.5 除法器的异常与结构

除法器由 ALU、寄存器、移位器、计数器和控制逻辑组成。除数为 0 时通常由硬件检测并触发异常/中断处理。

## 6. 高频综合辨析

### 6.1 加法器到底能做什么

同一个 n 位加法器可以完成：

```text
无符号加法
无符号减法（模2^n）
补码有符号加法
补码有符号减法
```

硬件只产生 n 位结果与标志位；结果按有符号还是无符号解释，由指令语义决定。

### 6.2 结果位串与数学结果

例如 8 位：

```text
11111111 + 00000001 = 00000000，Cout=1
```

- 按无符号：255+1 超出范围，CF=1。
- 按有符号：-1+1=0，不溢出，OF=0。

### 6.3 双字长为什么重要

- n 位加减结果仍按 n 位保存。
- n 位乘 n 位的完整乘积需要 2n 位。
- 除法中被除数常需扩展为 2n 位，并在迭代中联合移位。

## 高频易错点

- [ ] 把串行进位误解为各数位分多个时钟周期串行计算
- [ ] 认为算术右移高位永远补 1
- [ ] 补码左移时忽略符号变化和溢出
- [ ] 最高位进位丢弃后就认为一定没有溢出
- [ ] 用 CF 判断有符号溢出，或用 OF 判断无符号溢出
- [ ] 忘记本书统一加减器 `CF=Sub XOR Cout`
- [ ] 有符号比较时只看 SF，不用 OF 修正
- [ ] 认为异号数相加也可能发生补码溢出
- [ ] 乘法只保留低 n 位却不检查高 n 位
- [ ] 原码乘法中把符号位当普通数值位相乘
- [ ] 除法忘记先判断除零、被除数为零和被除数较小等情况
- [ ] 把恢复余数法与加减交替法步骤混用
- [ ] 忽略最小负数除以 -1 的商溢出

## 一页背诵版

```text
全加器：Si=Ai XOR Bi XOR Ci-1
串行进位：结构简单，进位链慢
并行进位：提前并行形成进位，速度快

补码加减：符号位参与，最高进位舍弃
[A-B]补=[A]补+[-B]补
OF=Cn XOR Cn-1
CF=Sub XOR Cout
ZF：结果为0
SF：结果最高位

无符号比较(A-B)：ZF判等，CF=1判A<B
有符号比较(A-B)：ZF判等，SF XOR OF判小于

逻辑右移补0；补码算术右移补符号位

乘法：部分积+移位，n×n完整结果2n位
无符号乘法不溢出：高n位全0
补码乘法不溢出：高n位是低n位符号扩展

恢复余数除法：左移、试减、定商、必要时恢复
除数为0：异常
补码特殊溢出：最小负数/(-1)
```

## 自测

1. 写出一位全加器的和与进位表达式。
2. 说明串行进位慢在哪里。
3. 8 位补码 `10010101` 算术右移一位得到什么？
4. 为什么异号数相加不会发生补码溢出？
5. 写出 OF、CF 在本书加减器中的表达式。
6. 执行 `A-B` 后，如何用标志位分别判断无符号和有符号的 `A<B`？
7. 为什么 n 位乘 n 位通常要用 2n 位保存完整结果？
8. 恢复余数除法发现试减结果为负时做什么？
9. n 位补码除法中哪一种操作会产生唯一的商溢出？

### 自测答案

1. `S_i=A_i XOR B_i XOR C_(i-1)`；`C_i=A_iB_i+(A_i XOR B_i)C_(i-1)`。
2. 高位进位要等待低位逐级传播，关键路径随字长增长。
3. `11001010`。
4. 两数真值介于一正一负之间，其和不会越过补码两端界限。
5. `OF=C_n XOR C_(n-1)`；`CF=Sub XOR C_out`。
6. 无符号：`CF=1`；有符号：`ZF=0` 且 `SF XOR OF=1`。
7. 最大乘积的有效位数可达 2n 位。
8. 当前商位置 0，并执行 `R<-R+Y` 恢复余数。
9. 最小负数除以 `-1`。
