## 全章主线

```text
CPU寄存器 -> Cache -> 主存 -> 外存
速度：由左向右降低
容量：由左向右增大
每位成本：由左向右降低
```

层次结构依靠程序访问的时间局部性和空间局部性，在“速度、容量、成本”之间折中。

## 必背公式

```text
存储容量 = 存储字数 × 字长
SRAM容量 = 行数 × 列数
DRAM地址引脚复用：行、列地址分两次送入

磁盘平均存取时间 = 寻道时间 + 旋转延迟 + 传输时间

Cache命中率 h = 命中次数/总访问次数
平均访问时间 = h×命中时间 + (1-h)×未命中代价（按题目口径）

直接映射：Cache行号 = 主存块号 mod Cache行数
组相联：组号 = 主存块号 mod Cache组数

页内偏移位数 = log2(页面大小)
虚页号位数 = 虚拟地址位数 - 页内偏移位数
```
