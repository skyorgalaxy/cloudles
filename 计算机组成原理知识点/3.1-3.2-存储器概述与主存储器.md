# 3.1-3.2 存储器概述与主存储器

> 原书：第77-97页；PDF第88-108页
>
> 核心：存储层次、性能指标、SRAM、DRAM、ROM

## 1. 存储器分类

### 按层次

| 层次 | 典型器件 | 特点 |
| --- | --- | --- |
| 寄存器 | CPU 内部寄存器 | 最快、最小、最贵 |
| Cache | SRAM | 缓解 CPU 与主存速度差 |
| 主存 | DRAM | CPU 可直接访问的工作存储器 |
| 辅存 | SSD、磁盘 | 容量大、非易失、CPU 不能直接按普通指令访问 |

### 按存取方式

- 随机存取 RAM：任一地址存取时间基本相同。
- 只读存储器 ROM：正常工作时主要读取，通常非易失。
- 顺序存取 SAM：访问时间与位置有关，如磁带。
- 直接存取 DAM：先定位区域再顺序访问，如磁盘。
- 相联存储器 CAM：按内容而非地址查找，TLB 可采用相联比较。

### 按断电后信息是否保留

- 易失性：SRAM、DRAM。
- 非易失性：ROM、Flash、磁盘、SSD。

## 2. 基本性能指标

- 存储容量：`存储字数 × 字长`，也可用字节表示。
- 存取时间 `T_a`：启动一次访问到完成访问所需时间。
- 存取周期 `T_m`：连续两次独立访问的最小间隔，通常 `T_m >= T_a`。
- 主存带宽：单位时间传送的数据量。

> [!warning] 存取周期不等于存取时间
> 某些存储器完成读写后还需恢复，因此存取周期更长。

## 3. 存储系统层次

```text
Cache-主存：主要解决速度问题，由硬件自动管理
主存-辅存：主要解决容量问题，由硬件和操作系统共同管理，形成虚拟存储器
```

局部性：

- 时间局部性：刚访问的数据/指令很可能再次访问。
- 空间局部性：刚访问位置附近的内容很可能很快被访问。

## 4. SRAM

SRAM 单元通常由双稳态触发器保存 1 bit：

- 只要不断电，信息可稳定保持，不需刷新；
- 读出通常是非破坏性的；
- 速度快、集成度低、成本高；
- 常用于 Cache。

典型 SRAM 芯片信号：地址线、数据线、片选 `CS`、读写控制 `WE/OE`。

## 5. DRAM

DRAM 用电容是否存有电荷表示 0/1：

- 电荷会泄漏，必须定期刷新；
- 读出具有破坏性，读后需再生；
- 集成度高、容量大、成本低；
- 常用于主存。

### 地址复用

DRAM 将地址拆成行地址和列地址，分两次送入同一组地址引脚：

```text
先送行地址，由 RAS 锁存
再送列地址，由 CAS 锁存
```

若有 `2^r × 2^c` 个单元，非复用需 `r+c` 根地址线，复用后通常只需 `max(r,c)` 根。

### 刷新

刷新只需按行进行，刷新周期内必须把全部行刷新一次。

- 集中刷新：在一段专门时间连续刷新全部行，存在较长“死时间”。
- 分散刷新：每个存取周期后安排一次刷新，无长死时间但存取周期变长。
- 异步刷新：把各行刷新均匀分散到刷新周期内，兼顾二者，常考。

刷新地址由刷新计数器给出，通常不需要外部提供完整地址。

## 6. SRAM 与 DRAM 对比

| 项目 | SRAM | DRAM |
| --- | --- | --- |
| 存储元件 | 双稳态电路 | 电容 |
| 刷新 | 不需要 | 需要 |
| 读出 | 非破坏性 | 破坏性，需再生 |
| 速度 | 快 | 较慢 |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |
| 典型用途 | Cache | 主存 |

## 7. ROM 与 Flash

- MROM：出厂写入，不能修改。
- PROM：用户可写一次。
- EPROM：紫外线擦除，可重复写。
- EEPROM：电擦除，可按字节修改。
- Flash：电擦除，通常按块擦除，密度高；SSD 常以 Flash 为介质。

ROM 是“随机读取”的存储器，“只读”不等于只能顺序访问，也不等于任何 ROM 永远不能改写。

## 8. 多模块存储器

为提高带宽，可把主存分成多个可并行工作的模块。

### 单体多字存储器

一次读出连续多个存储字，适合连续访问，但遇到分支或不连续地址利用率下降。

### 多体并行存储器

- 高位交叉编址：高位选模块，低位为模块内地址；连续地址集中在同一模块，不利于流水访问。
- 低位交叉编址：低位选模块，高位为模块内地址；连续地址轮流分布到各模块，可流水启动。

若模块数为 m、每模块存取周期为 T，为实现无冲突流水，连续启动间隔 `t` 应满足 `m >= T/t`。

## 易错点

- [ ] 把 RAM 等同于易失性存储器的全部，把 ROM 等同于不可随机访问
- [ ] 混淆存取时间与存取周期
- [ ] 认为 DRAM 刷新逐单元进行，而不是逐行
- [ ] 认为 DRAM 地址复用减少了地址空间
- [ ] 把 SRAM/DRAM 的用途和刷新特性写反
- [ ] 认为 Cache-主存主要解决容量问题
- [ ] 把高位交叉当作连续地址轮流分布

## 一页背诵版

```text
SRAM：触发器、不刷新、非破坏读、快贵，用于Cache
DRAM：电容、要刷新、破坏读、密度高，用于主存
集中刷新有死时间；异步刷新均匀分散

Cache-主存解决速度
主存-辅存解决容量
依据：时间局部性 + 空间局部性

低位交叉：连续地址分散到不同模块，利于流水
高位交叉：连续地址集中在同一模块
```
