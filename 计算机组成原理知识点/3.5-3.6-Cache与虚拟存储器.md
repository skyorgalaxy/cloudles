# 3.5-3.6 Cache 与虚拟存储器

> 原书：第109-147页；PDF第120-158页
>
> 核心：Cache 映射、替换与写策略，分页、页表、TLB 和多级存储联合访问

## 1. Cache 基本原理

Cache 保存主存中一部分数据的副本，以“块”为单位调入。CPU 地址一般拆为：

```text
主存块标记 Tag | 组/行索引 Index | 块内偏移 Offset
```

块大小为 `2^b B`，则块内偏移 b 位。Cache 数据区大小 = 行数 × 块大小，不含标记和有效位等额外开销。

### 命中与缺失

- 命中：对应块在 Cache，直接读取。
- 缺失：从下一级存储调入；若目标位置已满，按规则替换。

命中率：`h = 命中次数/总访问次数`。

常见平均时间口径：

```text
并行查找口径：T = h×Tc + (1-h)×Tm
先查Cache再访主存：T = Tc + (1-h)×缺失额外代价
```

必须按题目对“未命中时间”是否包含 Cache 查询时间的定义列式。

## 2. 三种映射方式

### 直接映射

```text
Cache行号 = 主存块号 mod Cache行数
```

- 每个主存块只能放固定一行；
- 硬件简单、速度快；
- 冲突缺失多，无须替换算法。

### 全相联映射

- 主存块可放任意 Cache 行；
- 冲突最少；
- 需同时比较所有标记，硬件成本高；
- 需要替换算法。

### 组相联映射

Cache 分若干组，每组 k 行：

```text
组号 = 主存块号 mod 组数
块可放入目标组内任意一行
```

k 路组相联在成本和冲突率之间折中。直接映射是 1 路组相联，全相联可看作只有 1 组。

## 3. 地址位划分

若主存按字节编址、地址 m 位，Cache 有 `2^s` 组，块大小 `2^b B`：

```text
块内偏移 b 位
组索引 s 位
Tag = m-s-b 位
```

若块含多个字，还可把块内偏移细分为“字偏移 + 字节偏移”。

Cache 总位数计算必须加上：数据位、Tag、有效位，以及题目给出的脏位、替换位等。

## 4. 替换算法

- 随机 RAND：简单。
- 先进先出 FIFO：替换最早进入的块，可能出现 Belady 异常思想上的反直觉。
- 最近最少使用 LRU：替换最长时间未访问的块，利用时间局部性，硬件开销随路数增加。
- 最不经常使用 LFU：按访问次数替换，需维护计数。

直接映射位置唯一，不需要选择牺牲块。

## 5. 写策略

### 写命中

- 全写法 Write-through：同时写 Cache 和主存，一致性简单，写流量大，常配写缓冲。
- 回写法 Write-back：只改 Cache 并置脏位，替换脏块时才写回主存，流量小、控制复杂。

### 写不命中

- 写分配 Write-allocate：先把块调入 Cache 再写，常与回写搭配。
- 非写分配 No-write-allocate：直接写下一级，不调块，常与全写搭配。

## 6. Cache 一致性

多核处理器中，同一主存块可能在多个私有 Cache 中有副本；一个核心写入后必须通过一致性协议使其他副本更新或失效。Cache 一致性不同于“主存与磁盘一致性”。

## 7. 虚拟存储器

虚拟存储器把主存作为辅存的缓存，为进程提供统一、较大的虚拟地址空间，并支持隔离和保护。

### 分页

```text
虚拟地址 = 虚页号 VPN | 页内偏移
物理地址 = 物理页框号 PPN | 页内偏移
```

页面与页框大小相等，地址转换只替换页号，页内偏移不变。

若页面大小 `2^p B`，页内偏移 p 位。页表项通常含物理页框号、有效/存在位、访问权限、脏位、访问位等。

### 页表

页表位于主存，页表基址寄存器给出当前进程页表位置。若每次先访问页表再访问数据，至少需两次主存访问，因此引入 TLB。

多级页表只为实际使用的地址范围逐级分配页表，可节省连续大页表空间，但 TLB 未命中时页表遍历次数增加。

### TLB

TLB 是页表项的高速缓存，通常采用相联或组相联查找：

- TLB 命中：直接得到物理页框号。
- TLB 未命中但页表项有效：查主存页表并回填 TLB。
- 页表项无效/不在主存：缺页异常，由操作系统调页。

> [!warning] TLB 未命中不等于缺页
> TLB 未命中只说明快表无该映射；页表中可能存在有效项。

## 8. 页式、段式与段页式

- 页式：定长页，便于管理，无外部碎片但有页内碎片。
- 段式：按程序逻辑划分变长段，便于共享保护，但有外部碎片。
- 段页式：先分段、段内分页，兼顾逻辑保护与物理管理，转换层次更多。

## 9. Cache 与虚拟存储器比较

| 项目 | Cache | 虚拟存储器 |
| --- | --- | --- |
| 上下层 | Cache-主存 | 主存-辅存 |
| 主要目标 | 提高速度 | 扩大容量并提供隔离 |
| 调入单位 | Cache 块 | 页/段 |
| 缺失处理 | 主要由硬件 | 操作系统参与 |
| 替换代价 | 较低 | 很高，可能涉及磁盘 |
| 程序员可见性 | 通常透明 | 提供虚拟地址空间 |

## 10. TLB、页表与 Cache 联合访问

典型流程：

```text
虚拟地址
 -> 用VPN查TLB
 -> 得到PPN，组成物理地址
 -> 用物理地址查Cache
 -> Cache未命中再访主存
```

若 Cache 使用物理地址，必须先完成地址转换；有些实现可让 TLB 查询与 Cache 索引并行，但考试按题设结构分析。

三种异常不要混淆：

```text
TLB miss：去查页表
Cache miss：去主存取块
Page fault：页不在主存，OS从外存调页
```

## 易错点

- [ ] Cache 容量计算把标记开销算进“数据区容量”或反过来
- [ ] 直接映射用字节地址直接取模，未先求主存块号
- [ ] 组相联把“行数”误当“组数”
- [ ] 全相联仍划分组索引位
- [ ] 直接映射使用 LRU
- [ ] 混淆回写/全写与写分配/非写分配
- [ ] 平均访问时间重复或漏算 Cache 查询时间
- [ ] 页号转换后错误地改变页内偏移
- [ ] TLB 未命中就判定缺页
- [ ] 把页表、TLB 和 Cache 当成同一种结构

## 一页背诵版

```text
直接映射：行=块号 mod 行数
组相联：组=块号 mod 组数
全相联：任意行

地址：Tag | Index | Offset
块大小2^b B -> Offset b位

写命中：全写 / 回写
写不命中：写分配 / 非写分配

虚拟地址：VPN | 页内偏移
物理地址：PPN | 页内偏移
TLB缓存页表项，Cache缓存主存块
TLB miss != Page fault
```

## 自测

1. 32 位字节地址、块 64B、Cache 16KB、4 路组相联，求 Offset、Index、Tag 位数。
2. 直接映射为何不需要替换算法？
3. 回写法为什么需要脏位？
4. TLB 未命中后可能出现哪两种结果？
5. 页面大小 4KB 时页内偏移多少位？

### 答案

1. 64B 得 6 位偏移；组数 `16KB/(64B×4)=64` 得 6 位索引；Tag 20 位。
4. 页表项有效则回填 TLB；页不在主存则缺页异常。
5. 12 位。
