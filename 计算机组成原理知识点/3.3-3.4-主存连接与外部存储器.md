# 3.3-3.4 主存连接与外部存储器

> 原书：第97-109页；PDF第108-120页
>
> 核心：芯片扩展、地址译码、磁盘与 SSD

## 1. 主存容量扩展

### 芯片容量

`2^k × b` 芯片表示有 `2^k` 个存储单元，每单元 b 位：

```text
地址线 k 根
数据线 b 根
总容量 2^k × b bit
```

### 位扩展

芯片字数够、字长不够时，多片并联：

- 地址线、片选线、读写线并联；
- 各芯片分别提供数据总线的一部分；
- 所需片数 = 目标字长 / 单片字长。

### 字扩展

芯片字长够、字数不够时分组：

- 低位地址连接所有芯片作片内地址；
- 高位地址经译码器产生片选；
- 同一时刻只选中一组。

### 字位同时扩展

先按位扩展组成一组，再按字扩展增加组数：

```text
总片数 = (目标字数/芯片字数) × (目标字长/芯片字长)
```

## 2. 地址译码与片选

- 线选法：一根高位地址线直接选一片，简单但地址空间利用率低，易有地址重叠。
- 译码片选法：高位地址经译码器生成互斥片选，地址范围清晰。

做题模板：

```text
1. 写目标容量与芯片规格
2. 算位扩展片数和字扩展组数
3. 低位地址作片内地址
4. 高位地址作组选择/译码
5. 根据固定高位写出起止地址
```

注意按字节编址还是按字编址。按字节编址时，一个地址对应 1B；数据总线宽度不改变地址的基本单位。

## 3. CPU 与存储芯片连接

主要连接：

- 地址总线：选择存储单元和芯片组。
- 数据总线：传输数据，位数应与一次传送宽度匹配。
- 控制总线：读、写、片选等控制。

CPU 地址线多于芯片所需时，未用于片内地址的高位不能悬空，应参与片选译码，否则产生地址镜像。

## 4. 磁盘存储器

### 结构与地址

磁盘由盘片、盘面、磁道、扇区、读写磁头和驱动机构组成。传统地址可表示为：

```text
柱面号（磁道） + 盘面号（磁头） + 扇区号
```

容量近似：

```text
磁盘容量 = 盘面数 × 每面磁道数 × 每道扇区数 × 每扇区字节数
```

### 性能指标

```text
平均存取时间 = 平均寻道时间 + 平均旋转延迟 + 数据传输时间
```

转速为 r 转/秒：

```text
平均旋转延迟 = 半圈时间 = 1/(2r)
```

内部传输率主要由转速、每道容量决定；外部传输率还受接口和控制器影响。

### 磁盘阵列 RAID

- RAID 0：条带化，无冗余，性能和容量利用率高，可靠性低。
- RAID 1：镜像，可靠性高，容量利用率约 50%。
- RAID 5：块级条带 + 分布式奇偶校验，可容忍一块盘故障。

## 5. 固态硬盘 SSD

SSD 以 Flash 为介质，由闪存芯片和闪存翻译层 FTL 等组成。

特点：

- 无机械寻道和旋转延迟，随机访问快、抗震、低功耗；
- 写入前通常需先擦除，擦除按块、读写按页；
- 擦写次数有限，需要磨损均衡；
- FTL 完成逻辑块地址到物理页映射、垃圾回收等。

| 项目 | 磁盘 | SSD |
| --- | --- | --- |
| 介质 | 磁性盘片 | Flash |
| 机械部件 | 有 | 无 |
| 随机访问 | 慢 | 快 |
| 写入限制 | 可覆盖 | 通常先擦后写 |
| 主要寿命因素 | 机械磨损 | 擦写次数 |

## 易错点

- [ ] 把 `2^k×b` 中 k 当数据线数
- [ ] 位扩展时用高位地址做片选
- [ ] 字扩展时所有芯片同时片选
- [ ] 忽略按字节编址与按字编址差异
- [ ] 磁盘平均访问时间漏掉寻道或旋转延迟
- [ ] 平均旋转延迟算成一整圈
- [ ] 认为 SSD 可直接覆盖写且没有寿命限制
- [ ] 把 RAID 0 当成有容错能力

## 自测

1. 用 `1K×4` 芯片组成 `4K×16` 存储器需要多少片？
2. 哪些地址位作片内地址，哪些作片选？
3. 磁盘平均存取时间由哪三部分组成？
4. 7200 r/min 磁盘平均旋转延迟约多少？
5. SSD 为什么需要 FTL 和磨损均衡？

### 答案

1. 位扩展 4 片、字扩展 4 组，共 16 片。
4. 每转约 8.33ms，平均半转约 4.17ms。
